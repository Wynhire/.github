# Wynhire

Resume builder and ATS checker, available in English, British English, French, Spanish, German and Italian: [wynhire.com](https://wynhire.com).

We publish what we measure. Our public research:

- **[ATS template study 2026](https://github.com/Wynhire/ats-template-study-2026)** — 29 resume templates rendered to PDF, text layer extracted the way a parser does, compared token by token with the source. Data, PDFs and the measurement script, under open licenses. Read the write-up: [wynhire.com/blog/ats-template-study-2026](https://wynhire.com/blog/ats-template-study-2026).
- **Explainer videos** on what applicant tracking systems actually read, with real test files: [youtube.com/@wynhire](https://www.youtube.com/@wynhire).

Questions about the data or the method: contact@wynhire.com.
